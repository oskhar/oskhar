Berikut adalah daftar lengkap pintasan keyboard dan perintah yang benar-benar lengkap untuk qutebrowser, browser berbasis keyboard yang sangat efisien. Semua kombinasi tombol dan perintah berikut akan membantu Anda meningkatkan produktivitas saat menggunakan qutebrowser.

### **Navigasi Halaman:**

| Kombinasi Tombol      | Deskripsi                              |
|-----------------------|----------------------------------------|
| `J` atau `↓`          | Gulir halaman satu baris ke bawah      |
| `K` atau `↑`          | Gulir halaman satu baris ke atas       |
| `H` atau `←`          | Gulir halaman satu kolom ke kiri       |
| `L` atau `→`          | Gulir halaman satu kolom ke kanan      |
| `Ctrl + F`            | Gulir halaman satu layar ke bawah      |
| `Ctrl + B`            | Gulir halaman satu layar ke atas       |
| `Ctrl + D`            | Gulir halaman setengah layar ke bawah  |
| `Ctrl + U`            | Gulir halaman setengah layar ke atas   |
| `+`                   | Perbesar tampilan halaman              |
| `-`                   | Perkecil tampilan halaman              |
| `=`                   | Kembalikan tampilan ke ukuran default  |
| `Shift + G`           | Gulir ke bagian bawah halaman          |
| `GG`                  | Gulir ke bagian atas halaman           |
| `` ` ``               | Tandai posisi saat ini                 |
| `'`                   | Gulir ke posisi yang ditandai sebelumnya |

### **Manajemen Tab:**

| Kombinasi Tombol        | Deskripsi                                        |
|-------------------------|--------------------------------------------------|
| `o`                     | Buka URL baru                                    |
| `Shift + O`             | Edit URL saat ini                                |
| `Ctrl + T`              | Buka tab baru                                    |
| `Ctrl + W`              | Tutup tab saat ini                               |
| `Ctrl + Shift + T`      | Buka kembali tab yang baru saja ditutup          |
| `J` atau `K`            | Pindah ke tab berikutnya atau sebelumnya         |
| `Shift + J` atau `Shift + K` | Pindah ke tab berikutnya atau sebelumnya dengan melompati tab yang dipilih |
| `Ctrl + Tab` atau `Ctrl + Page Down` | Pindah ke tab berikutnya                  |
| `Ctrl + Shift + Tab` atau `Ctrl + Page Up` | Pindah ke tab sebelumnya         |
| `Ctrl + 1` hingga `Ctrl + 8` | Pindah ke tab ke-1 hingga ke-8                |
| `Ctrl + 9`              | Pindah ke tab terakhir                          |
| `d`                     | Tutup tab saat ini                              |
| `Shift + d`             | Tutup semua tab kecuali yang saat ini           |
| `Ctrl + Shift + d`      | Duplikasi tab saat ini                          |
| `g` kemudian `t`        | Pindah ke tab dengan judul tertentu             |
| `g` kemudian `n`        | Pindah ke tab berikutnya                        |
| `g` kemudian `p`        | Pindah ke tab sebelumnya                        |

### **Navigasi Sejarah:**

| Kombinasi Tombol | Deskripsi                              |
|------------------|----------------------------------------|
| `H`              | Kembali ke halaman sebelumnya          |
| `L`              | Maju ke halaman berikutnya             |
| `Shift + H`      | Kembali ke halaman sebelumnya di tab baru |
| `Shift + L`      | Maju ke halaman berikutnya di tab baru |

### **Pencarian dan Pengambilan Tautan:**

| Kombinasi Tombol | Deskripsi                              |
|------------------|----------------------------------------|
| `/`              | Mulai pencarian ke depan               |
| `?`              | Mulai pencarian ke belakang            |
| `n`              | Pindah ke hasil pencarian berikutnya   |
| `Shift + n`      | Pindah ke hasil pencarian sebelumnya   |
| `N`              | Pindah ke hasil pencarian berikutnya dengan urutan terbalik |
| `Shift + N`      | Pindah ke hasil pencarian sebelumnya dengan urutan terbalik |
| `f`              | Tampilkan petunjuk tautan              |
| `Shift + f`      | Tampilkan petunjuk tautan di tab baru  |
| `;b`             | Tampilkan petunjuk bookmark            |
| `;B`             | Tampilkan petunjuk bookmark di tab baru |
| `;i`             | Tampilkan petunjuk gambar              |
| `;I`             | Tampilkan petunjuk gambar di tab baru  |
| `;t`             | Tampilkan petunjuk form input          |
| `;T`             | Tampilkan petunjuk form input di tab baru |
| `;o`             | Tempelkan URL yang dipilih ke bilah alamat |
| `;O`             | Tempelkan URL yang dipilih ke bilah alamat dan buka di tab baru |
| `;y`             | Salin URL yang dipilih ke clipboard   |
| `;Y`             | Salin URL yang dipilih ke selection buffer |
| `;r`             | Aktifkan Rapid Hint Mode               |
| `;R`             | Aktifkan Rapid Hint Mode dan buka di jendela baru |

### **Manajemen Bookmark dan Quickmark:**

| Kombinasi Tombol  | Deskripsi                              |
|-------------------|----------------------------------------|
| `m`               | Simpan tautan saat ini sebagai quickmark |
| `Shift + m`       | Simpan tautan saat ini sebagai bookmark |
| `b`               | Muat quickmark                         |
| `Shift + b`       | Muat bookmark                         |
| `wb`              | Muat quickmark di jendela baru         |
| `wb` kemudian `Shift + b` | Muat bookmark di jendela baru         |
| `;d`              | Tambahkan quickmark                    |
| `;D`              | Tambahkan bookmark                     |
| `;l`              | Daftar quickmark dan bookmark          |
| `;L`              | Daftar quickmark dan bookmark di tab baru |

### **Perintah dan Pengaturan:**

| Kombinasi Tombol  | Deskripsi                              |
|-------------------|----------------------------------------|
| `:`               | Buka baris perintah                    |
| `:` kemudian `q`  | Keluar dari qutebrowser                |
| `:` kemudian `wq` | Simpan sesi dan keluar dari qutebrowser |
| `:` kemudian `w`  | Simpan sesi                            |
| `:` kemudian `q!` | Keluar tanpa menyimpan sesi            |
| `:` kemudian `set`| Buka halaman pengaturan                |
| `:` kemudian `help`| Buka halaman bantuan                  |

### **Mode dan Pengeditan Teks:**

| Kombinasi Tombol | Deskripsi                              |
|------------------|----------------------------------------|
| `i`              | Masuk ke Insert Mode                   |
| `v`              | Masuk ke Visual Mode untuk memilih teks |
| `V`              | Pilih seluruh baris di halaman        |
| `d`              | Hapus teks yang dipilih dalam Visual Mode |
| `y`              | Salin teks yang dipilih dalam Visual Mode |
| `p`              | Tempelkan teks yang disalin di Visual Mode |
| `;`              | Mengakses perintah bookmark dan quickmark |
| `y`              | Salin tautan atau teks yang dipilih ke clipboard |

### **Perintah untuk Menyempurnakan Pengalaman Pengguna:**

| Perintah         | Deskripsi                              |
|------------------|----------------------------------------|
| `:open`          | Buka halaman dengan mengetik URL       |
| `:tabnew`        | Buka tab baru dengan URL yang diberikan |
| `:tabclose`      | Tutup tab saat ini                     |
| `:tabnext`       | Pindah ke tab berikutnya               |
| `:tabprev`       | Pindah ke tab sebelumnya               |
| `:history`       | Lihat riwayat penjelajahan             |
| `:downloads`     | Lihat riwayat unduhan                  |
| `:bookmarks`     | Lihat dan buka bookmark yang disimpan  |
| `:set`           | Ubah pengaturan browser                |
| `:config`        | Konfigurasi pengaturan lanjutan        |
| `:help`          | Tampilkan halaman bantuan              |
| `:quit`          | Keluar dari qutebrowser                |
| `:q!`            | Keluar tanpa menyimpan perubahan       |
| `:save`          | Simpan perubahan yang telah dibuat     |

### **Perintah Khusus untuk Halaman dan Pengaturan:**

| Perintah         | Deskripsi                              |
|------------------|----------------------------------------|
| `:set zoom`      | Atur tingkat zoom halaman              |
| `:set content`   | Atur pengaturan konten halaman         |
| `:set downloads` | Atur pengaturan unduhan                |
| `:set editor`    | Atur editor teks yang digunakan        |
| `:set fonts`     | Ubah pengaturan font tampilan halaman |
| `:set scroll`    | Atur pengaturan gulir halaman          |
| `:set proxy`     | Atur pengaturan proxy (jika diperlukan)|
| `:set user-agent`| Ubah user agent string                 |
| `:open`          | Buka halaman URL baru                  |

Dengan menggunakan semua pintasan dan perintah di atas, Anda dapat meningkatkan efisiensi dan produktivitas Anda saat menggunakan qutebrowser, menjadikan pengalaman browsing Anda lebih cepat dan menyenangkan.
