# 2. TUJUAN AKHIR

Setelah menonton video ini, penonton harus bisa menjelaskan dengan bahasa sendiri:

```text
1. Source code .java adalah input untuk compiler,
   bukan sesuatu yang langsung dijalankan JVM.

2. javac bekerja pada fase compile-time.

3. Kalau compilation gagal,
   class file baru tidak dihasilkan.

4. File .class berbeda dari source .java.

5. Class file berisi Java bytecode dan metadata
   dalam format yang dipahami JVM.

6. javap bisa digunakan untuk melihat representasi
   bytecode secara manusiawi tanpa membongkar binary manual.

7. Perintah:
       java Hello
   menjalankan Java launcher,
   memulai JVM, memuat class Hello,
   lalu menjalankan entry point-nya.

8. public static void main(String[] args)
   adalah entry point klasik program Java yang kita gunakan.

9. JVM adalah abstract machine/runtime.
   CPU fisik pada akhirnya tetap menjalankan instruction mesin,
   tetapi detail bagaimana JVM mencapai tahap itu
   belum menjadi materi episode ini.

10. Penonton bisa membedakan:
       COMPILE-TIME
       dan
       RUNTIME
```

# 16. REFERENSI UTAMA

## R1 — JDK `javac` Tool Specification

https://docs.oracle.com/en/java/javase/26/docs/specs/man/javac.html

Digunakan untuk:

- `javac` membaca Java source;
- compilation menghasilkan class files yang berjalan pada JVM;
- `.java` sebagai source file;
- `.class` sebagai class file.

## R2 — JDK 27 `java` Command

https://docs.oracle.com/en/java/javase/27/docs/specs/man/java.html

Digunakan untuk:

- `java` sebagai launcher aplikasi Java;
- launcher memulai JVM;
- class dijalankan melalui entry point;
- bentuk klasik `public static void main(String[] args)`;
- source-file mode `java Hello.java`.

## R3 — JDK 27 `javap` Command

https://docs.oracle.com/en/java/javase/27/docs/specs/man/javap.html

Digunakan untuk:

- `javap` sebagai class-file disassembler;
- option `-c` menampilkan Java bytecode instruction dari method.

## R4 — Java Virtual Machine Specification, Java SE 27

https://docs.oracle.com/javase/specs/jvms/se27/html/index.html

Digunakan sebagai specification utama JVM.

## R5 — JVM Specification — Introduction

https://docs.oracle.com/en/java/javase/27/docs/specs/jvms/jvms-1.html

Digunakan untuk:

- JVM adalah abstract machine;
- JVM mengetahui class-file binary format, bukan Java source language;
- class file membawa JVM instructions/bytecodes;
- JVM tidak harus diimplementasikan hanya sebagai interpreter.

## R6 — JVM Specification — Class File Format

https://docs.oracle.com/javase/specs/jvms/se26/html/jvms-4.html

Digunakan untuk:

- class file sebagai binary format;
- class file merepresentasikan class/interface/module;
- class file menyimpan struktur yang dibutuhkan JVM.

## R7 — JVM Specification — Loading, Linking, and Initializing

https://docs.oracle.com/javase/specs/jvms/se19/html/jvms-5.html

Digunakan hanya untuk framing umum bahwa class perlu dimuat ke runtime.

Episode ini **tidak** mengajarkan linking dan initialization secara detail.
