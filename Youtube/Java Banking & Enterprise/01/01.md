Episode ini **bukan** video untuk mengajari syntax Java secara penuh.

Episode ini juga **bukan** dokumenter sejarah Java.

Fungsinya adalah membangun **fondasi mental** sebelum penonton mulai belajar Java secara teknis pada video berikutnya.

Penonton masuk dengan kondisi:

```text
SUDAH:
- tahu apa itu programming secara umum;
- pernah melihat sedikit code;
- mungkin pernah melihat variable, if, loop, function/method.

BELUM WAJIB TAHU:
- JVM;
- JDK;
- bytecode;
- garbage collection;
- class file;
- Java internals;
- Spring;
- concurrency;
- banking backend.
```

Penonton selesai episode ini harus bisa menjelaskan dengan bahasa sendiri:

```text
1. Java tidak lahir sebagai “bahasa backend bank”.

2. Green Project muncul ketika Sun melihat software akan semakin
   penting di perangkat elektronik konsumen.

3. Perangkat berbeda memiliki hardware dan environment berbeda,
   sehingga software sulit dipindahkan jika terlalu terikat
   pada satu mesin.

4. Kebutuhan portability, reliability, dan simplicity ikut
   membentuk bahasa Oak.

5. Virtual machine dan bytecode membantu memisahkan program
   dari detail satu mesin fisik tertentu.

6. Ketika Internet berkembang, kebutuhan yang sama menjadi
   semakin relevan dan Oak berkembang menjadi Java.

7. Java language, javac, bytecode, JVM, dan JDK adalah
   hal yang berbeda dan masing-masing punya fungsi.

8. Java masih berkembang sampai sekarang dan tidak hanya
   bertahan karena legacy.

9. AI membantu menulis code, tetapi memahami sistem tetap
   diperlukan untuk menilai dan mengubah code dengan benar.

10. Penonton mampu melakukan sendiri:
    Hello.java
        ↓ javac
    Hello.class
        ↓ java / JVM
    output
```
